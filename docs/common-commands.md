# Common Commands

## Simulations
To run heater device simulation:
```bash
nx run @home-automation/simulations:simulate --name=heater
# OR
nx simulate @home-automation/simulations --name=heater
```

## Heater System
To run the heater system application:
```bash
nx run @home-automation/heater-system:simulate
# OR
nx simulate @home-automation/heater-system
```
